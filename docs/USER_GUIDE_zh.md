# RAW 实验室指南

本指南涵盖 LumaForge 的正常工作流：

```text
单张 RAW 文件 -> 预览 -> 风格或 LUT -> 对比 -> JPEG 导出
```

你不需要在使用前理解每一个色彩管理术语。记住一条简单的规则就好：
选你想要的风格，让 LumaForge 帮你在全分辨率路径能够复现该风格之前
把住导出关。

## 1. 打开 RAW 实验室

在现代浏览器中打开 `/raw`。配备 WebGPU 的桌面浏览器是推荐的运行环境。
移动端浏览器也能处理部分文件，但较大的 RAW 文件加上浏览器内存限制，
可能让体验不够稳定。

你的照片保留在你的设备上。LumaForge 不需要账户、云端上传、原生助手、
许可证管理器或本地守护进程。

## 2. 加载一张 RAW 文件

将 RAW 文件拖入实验室或使用文件选择器。LumaForge 围绕单张照片工作流
构建，因此请从一张源文件（而非文件夹或批量）开始。

支持的文件取决于浏览器运行时能够检查和解码的内容。常见的相机 RAW
扩展名（如 `.arw`、`.nef`、`.raf`、`.rw2`、`.orf`、`.dng`、`.cr2`、
`.cr3`、`.pef` 和 `.srw`）预期可用，但并非每种相机布局都能暴露安全
导出所需的信息。

## 3. 等待可用的预览

第一张可见图像可能来自嵌入式或快速预览。当浏览器和文件允许时，
LumaForge 随后会用更高质量的预览替换它。

预览用于交互和对比。导出是独立的：最终 JPEG 在该路径就绪时通过全分辨率
Worker 路径构建。

## 4. 选择风格

风格就是一个 `.cube` LUT，按你选择的强度应用。你也可以不用 LUT，只用影调
和色彩完成照片。

来自在线目录（例如默认的 LumaForge Profiles 目录）的 LUT 自带目录条目声明的
契约，无需你再选择。如果某个条目的契约无法读取，LumaForge 会在你选中它时报告
问题，你需要像对待自己的文件一样为该 LUT 选择契约。

对于你自己的 `.cube` LUT，请添加文件，并在 LumaForge 询问时选择输入和输出
契约。契约告诉应用该 LUT 期望什么类型的图像以及它产生什么类型的图像。
下次添加同一个 LUT 文件时，这个浏览器会记住你为它选的契约。

在线 LUT 目录只会在列出它的界面打开时才请求，例如桌面端 LUT 工具中的某个
目录来源，或手机上的风格条与 LUT 来源面板。分享的 `?luts=` 链接会立即加载
它指定的目录。加载失败的目录会等你点“重试”或“刷新”。

不错的起点：

- 如果 LUT 的介绍中提到 Rec.709 或 sRGB，从显示 Rec.709/sRGB
  风格契约入手。
- 如果 LUT 是为相机 Log 配置文件制作的，选择对应的相机 Log 输入系列，
  如 ARRI LogC、Sony S-Log、Fujifilm F-Log、Canon Log、Nikon N-Log、
  Panasonic V-Log 或 RED Log3G10。
- 如果不确定，请预览结果，优先选择使肤色、天空、阴影和高光看起来
  合理的契约。避免产生死黑、荧光色或褪色对比度的契约，除非那正是你
  想要的效果。

更多示例请参见 [LUT 与导出常见问题](./LUT_AND_EXPORT_FAQ_zh.md)。

## 5. 导出前对比

使用对比模式检查原始和处理后的结果。这对强烈的 LUT 尤其有用，因为
一开始感觉良好的风格可能会将肤色、天空或阴影细节推得太过。

在手机上，轻点照片上的圆形对比镜头可打开或关闭分屏，按住它则可在松手前
查看原图。

没有 WebGPU 时，较慢的 CPU 预览没有分屏。你可以改为在原图和处理后的照片
之间切换：桌面端使用照片下方的“已处理”和“原始”按钮，手机上轻点对比镜头。

## 6. 调整与变换

“调整”包含影调、色彩（色温、色调、饱和度和自然饱和度）以及 HSL 控件。
“变换”用于校正和重新构图：自动校正模式、垂直与水平透视、旋转、比例、缩放
和偏移，默认裁掉空白边。导出会在全分辨率下复现这两类调整。

应用变换后，原图视图和分屏都不可用，因为预览只显示变换后的照片。重置变换
即可重新对比。

这些控件是为了帮你完成出片，目的不是把应用变成完整的桌面 RAW 编辑器。

## 7. 导出 JPEG

只有当 LumaForge 能够通过全分辨率导出路径重建所选源文件和色彩图谱时，
导出才可用。如果导出被禁用，请阅读状态消息，而不是假设预览图像可以
保存为最终结果。

这是刻意为之。LumaForge 宁可把导出拦住，也不愿悄悄导出一张低分辨率预览
或用不同于你批准的路径去生成 JPEG。

在手机上，导出按钮位于右上角。它会在照片仍然可见的情况下打开导出面板，
导出尚未就绪时会说明缺少什么。

修改变换后，导出会等到预览显示新的构图。如果变换留下的可用画面太少，或无法
在全分辨率下复现，导出会保持禁用，直到你减小或重置它。

JPEG 以固定的 0.92 质量写出。导出就绪后，你可以下载它，在浏览器支持时复制
或分享它，并在渲染清单封存后下载清单。无法复制 JPEG 的浏览器会改为复制一张
标明为预览尺寸的图像。如果之后又修改了照片，那张 JPEG 就不再与照片一致：
请重新导出后再交付。

为了给导出腾出内存，LumaForge 会在导出期间释放预览。导出完成后 JPEG 仍然
可用，点“恢复预览”即可让照片回来并继续编辑。

导出面板提供的 HQ 预览 JPEG 是由预览生成的较小文件（最多 1200 万像素）。它
标明为 HQ 预览，从不包含变换，也不是全分辨率导出。

如果同一文件上一次导出被中断（例如标签页被关闭或设备内存不足），当你在同一
浏览器中再次加载该文件时，导出面板可能会提示你，你下一次发起的导出会使用更
稳妥的设置。这次导出会从头开始：LumaForge 不会续写未完成的文件，也不会自行
导出。

## 快速故障排除

如果预览不显示：

- 尝试使用支持 WebGPU 的现代桌面浏览器。
- 尝试较小的 RAW 文件或来自同一相机的不同文件。
- 刷新页面并重新加载文件。

如果 LUT 结果看起来不对：

- 检查 LUT 是为显示 Rec.709/sRGB 还是相机 Log 配置文件制作的。
- 如果 LUT 名称提及某个相机 Log 系列，尝试匹配它。
- 在更改多个设置之前先降低风格强度。

如果导出不可用：

- 在实验室中检查导出状态。
- 确认源文件和 LUT 契约受支持。
- 将预览视为预览，而非最终导出路径。
