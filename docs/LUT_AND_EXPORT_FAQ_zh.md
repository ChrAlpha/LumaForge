# LUT 与导出常见问题

本页面解释最常困扰 RAW 摄影爱好者的问题：该选哪个 LUT 契约、为什么导出
可能不可用，以及预期的浏览器支持情况。

## 什么是 LUT 契约？

`.cube` LUT 是一张色彩查找表。它通常假设特定类型的输入图像，例如显示
Rec.709、ARRI LogC、Sony S-Log 或其他相机 Log 曲线。

契约告诉 LumaForge 两件事：

- 输入：LUT 期望什么类型的图像。
- 输出：LUT 产生什么类型的图像。

没有这些信息，同一个 LUT 可能看起来发灰、反差过大、过饱和，或完全不对劲。

## 我应该选择哪个契约？

来自在线目录（例如默认的 LumaForge Profiles 目录）的 LUT 在目录条目中声明
契约，LumaForge 会在你选中该 LUT 时读取它。如果条目的契约无法读取，LumaForge
会为该条目报告问题，该 LUT 也不会带有可信契约；请像对待你自己的 `.cube`
文件一样处理它。下面的问题针对这类文件。

首先参考 LUT 的名称、下载页面或文件夹名称。LUT 包通常会给出线索，
如 `Rec709`、`sRGB`、`LogC`、`SLog3`、`FLog`、`CLog`、`VLog` 或
`REDLog3G10`。

如果 LUT 面向成片视频、静态照片、Instagram 或一般照片编辑，它通常是
显示风格的 Rec.709/sRGB LUT。

如果 LUT 面向某个相机品牌或 Log 配置文件，选择对应的配置文件系列。
例如：

| LUT 线索                     | 尝试此输入系列            |
| ---------------------------- | ------------------------- |
| `Rec709`、`sRGB`、display    | Rec.709 / sRGB 风格输入   |
| `LogC`、`ARRI`               | ARRI LogC                 |
| `SLog`、`SLog3`、`Sony`      | Sony S-Log                |
| `FLog`、`F-Log`、`Fujifilm`  | Fujifilm F-Log            |
| `CLog`、`Canon Log`          | Canon Log                 |
| `N-Log`、`Nikon`             | Nikon N-Log               |
| `V-Log`、`Panasonic`         | Panasonic V-Log           |
| `REDLog3G10`、`RED`          | RED Log3G10               |

当两个选择看起来都可以时，对比肤色、天空、中性墙壁和深阴影。更好的契约
通常在添加额外校正之前看起来就已经正常。

## 为什么选错契约看起来这么糟糕？

创意 LUT 不是通用滤镜。为相机 Log 灰片设计的 LUT 与为普通显示图像
设计的 LUT，对亮度和色彩编码的假设完全不同。

应用错误的契约可能导致：

- 死黑或发灰的阴影；
- 裁切溢出的高光；
- 过饱和的红色和蓝色；
- 偏绿或偏洋红的肤色；
- 需要过多校正的平淡结果。

LumaForge 把契约选项亮出来，因为隐藏它只会让结果更不可信。

## 为什么导出被禁用？

预览和导出有不同的职责。预览应尽快可见。导出必须通过受支持的色彩路径
重建全分辨率 JPEG。

导出可能在以下情况被禁用：

- RAW 文件无法暴露安全导出所需的处理窗口信息；
- 浏览器对该文件的能力或内存不足；
- 所选 LUT 契约不完整或不受支持；
- 导出 Worker 无法证明它可以复现已预览的色彩图谱；
- 变换仍在预览上准备，留下的可用画面太少，或无法在全分辨率下复现。

这是一种防护措施。LumaForge 不应仅仅为了让下载按钮出现就悄悄保存低质量
预览或更改色彩路径。

导出面板提供的 HQ 预览 JPEG 会标明为 HQ 预览，由预览生成，最多 1200 万像素，
并且从不包含变换。它不能替代全分辨率导出。

## 中断的导出能续上吗？

不能。如果某个文件的导出被中断（例如标签页被关闭或设备内存不足），在同一
浏览器中再次加载该文件时，导出面板可能会给出提示，你下一次发起的导出会使用
更稳妥的设置。这次导出会从头开始。LumaForge 不会续写未完成的文件，不会要求你
重新选择源文件，也不会自行导出。

## LumaForge 会上传我的照片吗？

不会。所选 RAW 文件在浏览器中处理。正常工作流不需要账户、云端上传、
原生助手、许可证激活或本地守护进程。

在你交付期间，全分辨率 JPEG 可能会写入浏览器为本站保留的私有存储。当你再次
导出、重置、替换文件或离开实验室时，LumaForge 会删除它。已关闭的标签页留下
的文件通常会在之后某次访问的导出中被删除，而在该标签页仍打开时绝不会删除。

## 我应该使用哪个浏览器？

使用支持 WebGPU 的现代桌面浏览器以获得最佳基线体验。较大的 RAW 文件可能
会消耗大量浏览器内存，尤其是在移动设备上。

没有 WebGPU 时，预览改用较慢的 CPU 路径，且没有分屏。全分辨率导出不使用
WebGPU，因此在文件和浏览器内存允许时仍然可以进行。

移动端浏览器适用于实验和较小的文件，但它们不是大型全分辨率 RAW 导出的
最可靠目标。

## 这是 Lightroom 或 DaVinci 的替代品吗？

不是。LumaForge 刻意做得更聚焦。它的用途是用风格或 LUT 完成一张 RAW 照片，
并在路径安全时导出 JPEG。

当你需要目录管理、批量处理、遮罩、降噪、镜头校正、节点图或详细的专业
调色控件时，请使用完整的编辑器。

## 文件处理失败时该怎么办？

按以下顺序尝试：

1. 使用现代桌面浏览器。
2. 尝试来自同一相机的较小 RAW 文件。
3. 尝试目录中的 LUT，或不使用 LUT，而非自定义 LUT。
4. 如果需要自定义 LUT，从 LUT 包中确认契约。
5. 如果导出提示无法复现变换，重置变换。
6. 将无法支持的文件视作兼容性边界，不要强行导出。
